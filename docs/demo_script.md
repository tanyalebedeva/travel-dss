# Сценарий демонстрации (~5 минут)

1. `streamlit run app/streamlit_app.py`. В боковой панели оставить базовые параметры: май 2027, 5 дней,
   70 000 ₽, интерес к культуре и гастрономии. Вкладка «Итог»: три варианта —
   Санкт-Петербург («Оптимальный»), Калининград («Экономный»), Казань («Надёжный»).
2. Открыть «Оптимальный»: обоснование, предупреждения базы знаний, смета, карта маршрута, план по дням.
   Обратить внимание на две вероятности перерасхода: по типовой смете (2,8 %) и по построенному маршруту (29 %),
   поэтому система советует сверить цены или выбрать «Экономный».
3. Открыть «Надёжный»: стратегия бронирования здесь выбрана по критерию Гурвица — возвратный тариф,
   в отличие от «Оптимального», где по Байесу выгоднее невозвратный.
4. «Рейтинг направлений»: веса критериев и ОС, локальные приоритеты, причины исключения
   Рима, Стамбула, Антальи и Дубая (превышение бюджета).
5. «Риски»: подвигать α Гурвица и показать, как меняется лучшее решение; пороги срыва поездки;
   Монте-Карло (у Тбилиси вероятность выйти за бюджет 64 %).
6. «Прогноз цен» и «База знаний»: прогноз с интервалами, журнал срабатывания правил по направлениям.
7. Сменить параметры: июль, 7 дней, 120 000 ₽, «Еду с детьми», интересы: пляж 0,95, отдых с детьми 0,9,
   культура 0,2. Важность критериев — режим «Из профиля интересов» (веса пересчитаются сами).
   Нажать «Подобрать варианты»: Дубай исключён правилом «жара опасна для детей», лидером становится Сочи,
   «Экономным» — Калининград (в июле у Балтики купальный сезон).
8. Открыть дашборд Superset на http://localhost:8088.
